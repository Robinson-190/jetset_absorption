## Extra absorption models for use in the JetSeT code.

This work is a reimplimentation of the work done by the authors of "[Unified multiwavelength data analysis workflow with gammapy](https://doi.org/10.1051/0004-6361/202452349)" with direct use of their publicly posted data. Accordingly, their work must be mentioned if this work is used.

The data are availabe in the corresponding gitbub repository: [https://github.com/mireianievas/gammapy_mwl_workflow](https://github.com/mireianievas/gammapy_mwl_workflow/) , in the */Models/* folder.
